definition :

is non linear abstract datatype that stores elements in hierarchy.

examples in real life :
  • family tree.
  • table of contents of a book.
  • decisions trees.
tree terminologies :
  • node :

    • - each data item in a tree.

  • root :

    • - distinguished element that is the origin of the tree(first node in tree).

  • edge :

    • - connections between nodes.

  • parent :

    • - single node that directly precedes a node.

  • child :

    • - one or more nodes that directly follow a node.

  • degree of node :

    • - is the number of sub trees of a node.

  • degree of tree :

    • - is the maximum degree of node in a given tree.

  • leaf node(terminal node) :

    • - a node with degree 0.

  • depth of tree(height of tree) :

    • - is the maximum level of any node in a given tree.

binary tree :

an ordered tree with at most two children for each node.
