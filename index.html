Definition:

A non-linear abstract data type that stores elements in a hierarchy.

Examples in real life:
  • Family tree.
  • Table of contents of a book.
  • Decision trees.
Tree Terminologies:
  • Node:

    • - Each data item in a tree.

  • Root:

    • - The distinguished element that is the origin of the tree (first node in the tree).

  • Edge:

    • - Connections between nodes.

  • Parent:

    • - A single node that directly precedes another node.

  • Child:

    • - One or more nodes that directly follow a node.

  • Degree of Node:

    • - The number of subtrees of a node.

  • Degree of Tree:

    • - The maximum degree of a node in a given tree.

  • Leaf Node (Terminal Node):

    • - A node with degree 0.

  • Depth of Tree (Height of Tree):

    • - The maximum level of any node in a given tree.

Binary Tree:

An ordered tree with at most two children for each node.
